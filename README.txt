PromptVault India - static site
1. Put index.html and sw.js in a GitHub repo (root folder).
2. Render > New > Static Site > pick repo. Build command: empty. Publish directory: .
3. Open your .onrender.com link. Check yoursite/sw.js opens.
4. Monetag: add the Render link as a new site there (sw.js zone may need to be re-made for the new domain).
